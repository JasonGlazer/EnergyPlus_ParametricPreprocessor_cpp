# ParametricPreprocessor in C++

A C++17 port of the EnergyPlus `ParametricPreprocessor`. The original is the Fortran in
`resources/ParametricPreprocessor.f90`, kept here for reference.

The preprocessor expands an IDF that uses `Parametric:SetValueForRun`,
`Parametric:Logic`, `Parametric:RunControl`, `Parametric:FileNameSuffix` and embedded
`=expression` fields into one IDF per case. For every well-defined input it produces
exactly the same files and messages as the Fortran version. See
[PORTING_NOTES.md](PORTING_NOTES.md) for the details, the original's quirks that were kept
on purpose, and the few deliberate differences.

Rules for changing and testing the code, for people and coding agents, are in
[AGENTS.md](AGENTS.md).

## Layout

```
src/ParametricPreprocessor/   the program (drop-in replacement for src/ParametricPreprocessor in EnergyPlus)
  ParametricPreprocessor.hh/.cc
  main.cc
  CMakeLists.txt
tests/
  compare_outputs.py          runs the preprocessor and compares every file it writes
  check_console_output.py     checks that console output is never lost (about 1 minute)
  measure_coverage.py         line coverage of the tests for the Fortran and the C++ (needs gfortran, g++, gcov)
  make_inputs.py              generates every input file as a complete EnergyPlus 26.2 model
  check_energyplus.py         simulates every generated case file in EnergyPlus (needs EnergyPlus 26.2)
  inputs/, expected/          edge-case and coverage inputs with outputs generated by the Fortran original
                              (an .args file is a command-line case, e.g. an input path with a directory)
  inputs_cpp_only/, expected_cpp_only/  inputs where the Fortran has undefined behavior
resources/                    original Fortran source, CMake file, batch file and example IDFs
```

## Build and test

```bash
cmake -S . -B build/release -DCMAKE_BUILD_TYPE=Release
```

```bash
cmake --build build/release --config Release
```

```bash
ctest --test-dir build/release -C Release --output-on-failure
```

The tests need Python 3. To also build the original Fortran program and compare against it
directly (including the example files in `resources/`), configure with a Fortran compiler
available and `-DPARAMETRIC_DIFFERENTIAL_TESTS=ON`. For example, with MinGW and gfortran:

```bash
cmake -S . -B build/mingw -G "MinGW Makefiles" -DCMAKE_BUILD_TYPE=Release -DPARAMETRIC_DIFFERENTIAL_TESTS=ON
```

## Usage

```
ParametricPreprocessor <path>/<file>.idf
```

The output is written next to the input:

- one file per active case, `<file>-<suffix>.idf`
- `<file>.err`, only when there are errors or warnings
- `parametric.int`, the intermediate file

Set the environment variable `DeveloperFlag=Y` for verbose console output.
`resources/RunParam.bat` shows how EnergyPlus calls the program.

## Using in EnergyPlus

1. Replace the contents of `src/ParametricPreprocessor/` in the EnergyPlus tree with
   `src/ParametricPreprocessor/` from this repository.
2. The `CMakeLists.txt` links the EnergyPlus `project_options` and `project_warnings`
   targets when they exist.
3. It installs to `PreProcess/ParametricPreprocessor` like the Fortran target, so no
   Fortran compiler is needed for this tool any more.
